The big shift: agents leave chat and touch real systems

MCP becomes default plumbing

X launched a hosted Model Context Protocol (MCP) server, lowering friction for AI tools to access its API with user permissions. The move mirrors GitHub, Slack, Notion, Stripe, and Salesforce offering official MCP endpoints — a clear signal that agent tooling is standardizing around MCP.

Source: techcrunch.com, thenextweb.com

Computer use reaches consumer Macs

Google brought Gemini Spark to macOS, expanding it with third‑party app actions and custom MCP connections. Access is gated to the $99.99/month Google AI Ultra tier in the U.S., highlighting how premium and restricted desktop agents remain.

Source: ppc.land, aivanet.com

Trust and scope questions intensify

As agents monitor files, act asynchronously, and prepare for remote execution, scrutiny around permissions and unintended actions grows — especially for background desktop agents.

Source: techgenyz.com

Latest signals buyers should track

X & MCP infrastructure

X’s hosted MCP server doesn’t add new API powers, but it removes infrastructure overhead — making real‑time data easier for agents like Grok or Claude to analyze (posting remains restricted).
